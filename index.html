A digital logic design project implementing a 4-bit adder-subtractor circuit using logic gates and full adders. Daily Dengue Hospitalizations Forecasting

A machine learning research project forecasting daily dengue hospitalizations in Dhaka, Bangladesh. Compares four tree-based models (Random Forest, Gradient Boosting, XGBoost, and LightGBM) using weather variables, temporal lag features, and epidemiological data. Gradient Boosting achieved the best result with a CV R² of 0.9255 and an outbreak detection AUC of 0.986, supporting hospital resource planning during outbreak seasons.
