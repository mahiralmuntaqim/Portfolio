Digital Logic Design (Adder-Subtractor)

A digital logic design project implementing a 4-bit adder-subtractor circuit using logic gates and full adders. This circuit performs both addition and subtraction operations on binary numbers using 2's complement arithmetic, controlled by a mode selector signal. The design demonstrates fundamental concepts of combinational logic circuits and binary arithmetic operations.
